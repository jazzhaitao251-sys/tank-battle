# 坦克大战 (Tank Battle)

一个使用原生 HTML5 Canvas + JavaScript 实现的经典坦克大战小游戏。

## 🎮 在线试玩

直接在浏览器中打开 `tank-battle.html` 即可开始游戏。

## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| `W` | 向上移动 |
| `A` | 向左移动 |
| `S` | 向下移动 |
| `D` | 向右移动 |
| `空格` | 射击 |

## 🎯 游戏规则

- 控制绿色坦克移动和射击
- 消灭所有红色敌方坦克
- 保护自己的基地（金色星星）
- 砖墙可以被子弹击毁，铁墙无法击毁

## 🚀 本地运行

```bash
# 克隆仓库
git clone https://github.com/YOUR_USERNAME/tank-battle.git

# 进入目录
cd tank-battle

# 用浏览器打开
tank-battle.html
```

或者直接双击 `tank-battle.html` 文件。
